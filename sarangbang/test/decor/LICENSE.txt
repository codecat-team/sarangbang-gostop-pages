Background photos in this folder (B28 "decorate the room" backgrounds)

These photos are shown only behind the start and result screens, never under the cards.
Changes by codecat (all three files): downscaled to 1920 px wide and re-saved as JPEG
(quality 80, mozjpeg); camera metadata (EXIF, incl. GPS) removed. The picture itself is
not cropped, retouched or recoloured. At run time the game darkens and blurs the photo;
that overlay is not part of these files.
